# ARGUS

**Automated Real-time Guard for Uncovering Security Breaches**

ARGUS is an endpoint security, malware detection, and digital-forensics platform.

The core purpose of ARGUS is:

**Detect → Investigate → Trace → Assess Exposure → Contain → Remove → Report**

ARGUS should not behave like a simple antivirus. Its key differentiator is that after detecting a threat, it investigates what happened during the period in which the threat was active.
